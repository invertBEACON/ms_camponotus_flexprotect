# README

Data and analysis code for Allman et al. "Beyond a Reflex: Intraspecific Differences in the Flexible Self-Protection of Ants". 

## Directory structure
- data/
  - INSTAR_Allman_et_al.csv: metadata information for ethical and welfare considerations.
  - grooming_data.csv: raw behavioural observations (e.g. ID, body part groomed, time start, time stop, total duration).
  - pilot_data.csv: raw pilot observations (e.g. ID, caste, body part stimulated, time start, temperature of probe (degrees celsius)).
- code/
  - AntFlexProtect_analysis.R: full analysis script. Performs data cleaning, merging, modelling (GAMs, Beta Regression, Variable Dispersion Analysis), and figure generation.
- output+supplemental/
  - Output figures and supplemental material from the analysis, generated by code.
- AntFlexProtect_SupplementaryMaterial.docx — Compiled and cleaned supplemental material
- AntFlexProtect_ms.docx — Full manuscript
- AntFlexProtect_Coverpage.docx — Header details associated with the manuscript
